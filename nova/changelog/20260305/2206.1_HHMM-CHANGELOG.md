# Changelog — 2026-03-05 22:06

## Detect external file changes and prompt to reload

### Summary
When a file open in the editor is modified on disk by an external process (e.g., another editor, git, CLI tools), Novi now shows a notification banner at the top of the editor with "Reload" and "Ignore" buttons. Previously, external changes were silently ignored and the editor showed stale content.

### Root Cause
The file tree watcher (chokidar) was catching `change` events for file content modifications but explicitly discarding them — only `add`/`unlink`/`addDir`/`unlinkDir` were forwarded to the renderer.

### Implementation

#### `src/main/services/file-tree-watcher.ts`
- Changed the `change` event handler to emit the event instead of ignoring it
- Now forwards `{ type: 'change', path }` to the renderer like other event types

#### `src/renderer/components/App.ts`
- Added `pendingReloadBanners` set to track which files have active reload prompts
- Added `fileTreeOnChange` listener for `change` events in `setupIpcListeners()`
- Added `handleExternalFileChange(path)` method that:
  - Checks if the changed file is open in any tab
  - Skips prompting if the change was from our own save (file not dirty)
  - Shows a notification banner with "Reload" and "Ignore" buttons
  - On Reload: reads fresh content from disk, updates Monaco editor and tab
  - On Ignore: dismisses the banner
  - Prevents duplicate banners for the same file
